# Zangetsu Clean & Risk-Free Personal App Builder

Ei package-e tomar jonno duita upay dewa ache:
1. **Zangetsu Lite (`lib/main.dart`)**: 100% clean, tracker-free, cloud-login-free Flutter app jeta sorasori `index.json` manifest support kore.
2. **GitHub Actions Auto-APK Builder (`.github/workflows/`)**: PC-te Android Studio install charai GitHub-er free server diye 5 minute-e `.apk` file build korar script!

## Kivabe Free-te APK Build Korbe (No PC Load):
1. GitHub-e giye notun ekta **PRIVATE Repository** khulo.
2. Ei ZIP file-er vitorer sob file extract kore oi Private Repo-te upload koro.
3. Repo-r **Actions** tab-e jao -> **Build Clean Zangetsu Lite APK** (othoba full app chaile **Build Official Zangetsu APK**) select kore **Run workflow**-te click koro.
4. 4-5 minute por build shesh hole নিচে **Artifacts** theke APK download kore phone-e install kore nao!
